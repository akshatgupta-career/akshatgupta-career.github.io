# Akshat Gupta portfolio

## Put it online (free, GitHub Pages)
1. On GitHub, create a new public repo named exactly `akshatgupta-career.github.io`.
2. Upload every file in this folder (Add file > Upload files), then Commit.
3. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. In about a minute the site is live at https://akshatgupta-career.github.io

## Private visitor stats (only you can see them)
1. Sign up free at https://www.goatcounter.com and pick a code, e.g. `akshatgupta`.
2. In index.html, replace `YOURCODE` with that code and upload the file again.
3. Your dashboard (login required) shows visits, which role link was opened (/#pm, /#ba, /#risk, /#mo),
   which role tabs people clicked (events named role-pm, role-ba ...), country, device and referrer.

## Custom domain (optional, about Rs 600-900 a year)
1. Buy e.g. akshatgupta.in (GoDaddy, Namecheap, Hostinger).
2. Repo Settings > Pages > Custom domain: enter it. GitHub shows the DNS records to add at your registrar.
3. Tick "Enforce HTTPS" once it verifies.
